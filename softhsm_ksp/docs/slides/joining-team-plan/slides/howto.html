Seven rules, each one paid for

How to work in this codebase without re-learning its lessons

1 · Break it before you believe it

No claim lands without a fault injection that the suite catches. And restore the injection from a copy made beforehand, never from git — that has destroyed uncommitted work three times.

2 · Two tokens, two passes

One token cannot tell a working selection from an ignored one; one pass cannot see what the provider leaves behind. Each shortcut hid a real defect until the second was added.

3 · Never hand-edit the mock

It once invented two constants and mis-valued two more, and every test passed because the tests read the same wrong numbers. A checker now compares it to the real headers, values and typedef widths both.

4 · The function table is assigned by name

Designated initialisers, permanently. Positional initialisation put a key handle where a HANDLE * belonged and returned success to a caller that then waited forever.

5 · A grep for a fix can match the fix's comment

An audit once reported ten files as correct when none was: the pattern matched the sentence describing the include. Verify with the compiler, not with a search.

6 · The five static checks are the contract

Docs, counts, property tables and the registration script are all machine-compared to the code. They exist because a summary sitting next to a fact does not stay true — the most persistent defect here.

7 · Closing a capability row is two edits

Set the row Covered and delete its gap entry, then regenerate. A status change edits the existing row — appending a new ID left one capability with two rows, one of them asserting the opposite of the other, for three sessions.

And one habit to keep

When the authoritative source is out of reach, record the gap; do not fill it from memory. Both times this project guessed at a Microsoft constant, the guess was wrong and passed every test.

Hand this slide out rather than presenting it. Every rule here is the residue of a specific incident, and the incidents are written up in CLAUDE.md with enough detail to be convincing. Rule 1's second sentence is the one people skip and the one that has cost the most.
