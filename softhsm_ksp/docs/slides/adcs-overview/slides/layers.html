Two layers, one translation each way

The KSP_ layer speaks CNG and knows nothing about Cryptoki. The P11_ layer speaks PKCS#11 and knows nothing about handles or blobs. Everything hard lives on the boundary.

Module Owns The design decision inside it
ksp_provider.c Open, Close, FreeBuffer, algorithm advertisement Advertises the intersection of what the KSP maps and what the token has — never a list compiled into the DLL
ksp_key_ops.c Create, Open, Finalize, Enum, Delete A taken container name is NTE_EXISTS; an overwrite destroys the old objects only after the new key generates
ksp_crypto.c SignHash, Verify, Encrypt, Decrypt, Export, Import, ECDH Size queries answer from the key, never by starting a token operation that would be left unfinished
ksp_properties.c Get and Set, key and provider scope Export policy is writable only before FinalizeKey — the token fixes CKA_SENSITIVE at generation
p11_context.c Module load, C_Initialize, slot choice A failed initialisation is retried; one bad module path must not poison the provider until the host restarts
p11_session.c 16 sessions, login, per-scope pools Scope is a mandatory parameter on acquire — a defaulted one would let a forgotten call site hit the wrong token and report success
p11_utils.c Mechanisms, DER, key export ECDSA signatures pass through raw r‖s as v2.40 §2.3.1 mandates; the DER decoder is a fallback only
