Four contracts that shaped the code

Each of these was learned by breaking it

CNG calls everything twice

NULL buffer for the length, then again for the work. The first implementation answered the length by starting a token operation and returning without finishing it — the session went back into the pool live, and the next caller got CKR_OPERATION_ACTIVE. Lengths now come from the key.

The table is assigned by name

Designated initialisers against the SDK header, so a wrong slot name is a build error rather than a displaced function. Positional initialisation is permanently out — it once put a key handle where a HANDLE* belonged and returned success.

Every handle is a magic number

Handles are direct casts validated by dwMagic. All 26 slots are called with a bad handle in the suite, and completeness is enforced by comparing each probe against the real table slot by pointer — a new slot with no probe fails and names itself.

Misconfiguration fails closed

No PIN where one is required is NTE_PERM and a log line, never a silent attempt at 1234. Half-configured per-scope tokens, two labels resolving to one token, or a caller selection alongside them are all refused. Isolation that reports success without isolating is worse than none.
